# proyecto_rag_cugdl

1. Crear un ambiente virtual (conda o python) conda create --nombre_entorno
2. Activar ambiente virtual (conda) conda activate --nombre_entorno
3. Instalar requirements.txt (Si solo se desea usar el RAG, borrar "ragas" en el requirements.txt)

Para ejecutar consultas: 
    1. Modificar los modelos LLM y Embeddings en los archivos main.py y base.py
    2. Ejecutar archivo main.py

Nota: 
El programa tardará algunos minutos en vectorizar la base en la carpeta data (capítulo 10: Agujeros de Gusano y Viajes en el tiempo)
